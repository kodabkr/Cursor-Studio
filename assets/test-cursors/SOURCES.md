# Cursor samples

Five ready-to-drag PNGs downloaded from Kenney's asset packs on October 13, 2026. These are unmodified originals with friendly filenames. Every image has a transparent background.

| Sample | Suggested slot | Original file | Dimensions |
| --- | --- | --- | --- |
| `01-normal-arrow.png` | Normal pointer | `PNG/Outline/Default/pointer_a.png` | 32 x 32 |
| `02-hover-hand.png` | Hover / pointing hand | `PNG/Outline/Default/hand_point.png` | 32 x 32 |
| `03-pressed-hand.png` | Pressed / grab | `PNG/Outline/Default/hand_closed.png` | 32 x 32 |
| `04-shift-lock-ring.png` | Shift lock / aiming | `PNG/Outline/crosshair-006.png` | 74 x 74 |
| `05-crosshair-plus.png` | Shift lock / aiming alternative | `PNG/Outline/crosshair-020.png` | 74 x 74 |

The first three come from [Kenney Cursor Pack](https://kenney.nl/assets/cursor-pack) (v1.1). The two crosshairs come from [Kenney Crosshair Pack](https://kenney.nl/assets/crosshair-pack) (v1.1).

Both packs are [CC0 1.0 public domain](https://creativecommons.org/publicdomain/zero/1.0/). Personal and commercial use, modification, and redistribution are allowed; credit is appreciated but optional. The original license files are included alongside these PNGs.

Direct archive downloads used:

- [Cursor pack ZIP](https://kenney.nl/media/pages/assets/cursor-pack/461b29df18-1717599281/kenney_cursor-pack.zip)
- [Crosshair pack ZIP](https://kenney.nl/media/pages/assets/crosshair-pack/5ef74bd405-1785950072/kenney_crosshair-pack.zip)

Drag a PNG onto the matching slot in Roblox Cursor Modifier. The app previews and prepares the image before applying it. The filenames suggest uses for testing; these samples are not Roblox's original cursor artwork.
